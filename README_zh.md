# 三条件最小模拟包

精确使用 **α = 0.1、0.9、2**，各生成并模拟一个网络。每个网络有200个兴奋性神经元。三个条件共用同一组坐标，每个网络各有2000条有向边，具体边集合分别抽样。

## 使用方法

1. 根据论文 Data availability，从 https://codex.flywire.ai/ 获取 FlyWire v783 神经元空间坐标。
2. 准备含 `x,y,z` 列的CSV，或包含 `points`（N×3）/ `whole_v783.points` 的MAT文件。至少200行；三轴使用相同物理长度单位。
3. 在MATLAB中打开本目录并运行：

```matlab
runDir = run_representative('你的坐标文件的完整路径.mat');
```

也可指定输出父目录：

```matlab
runDir = run_representative('你的坐标文件的完整路径.csv', '你的输出目录');
```

输出自动写入新建的独立运行目录。包括网络、选中的坐标行号、参数和种子、输入及代码哈希、三个条件的脉冲记录和持续时间。每个完成的条件立即保存；重新运行会创建新目录。

使用基础MATLAB，不依赖BCT、Python、并行工具箱或原项目其他目录。模拟器的稠密脉冲缓冲区约占800 MB，需预留足够内存。

## 范围

原始空间坐标由使用者自行取得；公开包不附坐标或预计算结果。它只包含网络生成与模拟，不包括大规模扫描、预测划分、物理量分析和论文绘图。

本包生成新网络，使用精确的0.9和2；论文原来对应显示标签的采样值约为0.891808和1.976171。两者不混用。运行结果展示模型计算过程，不预设必须与论文选出的网络结果相同。

详细模型、输出字段和时间定义见英文 `README.md`。测试命令：

```matlab
results = runtests('tests/test_public_package.m');
assertSuccess(results);
```
